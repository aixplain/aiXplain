# Security Policy

## Supported versions

Security fixes are released for the latest published minor line of the
`aiXplain` SDK on PyPI. Older releases do not receive backported fixes; upgrade
to the latest release to pick them up.

## Reporting a vulnerability

**Please do not report security issues in public GitHub issues, pull requests or
discussions.**

Email [care@aixplain.com](mailto:care@aixplain.com) with the subject line
`SECURITY: aiXplain SDK` and include:

- the SDK version (`pip show aixplain`) and Python version;
- a description of the issue and its impact;
- steps or a minimal script to reproduce it;
- any suggested fix, if you have one.

Never include a real API key or other credential in a report. If one was exposed
while you were investigating, rotate it in aiXplain Studio.

We will acknowledge your report, keep you informed while we investigate, and
credit you in the release notes once a fix ships, unless you ask us not to.
Please give us reasonable time to release a fix before disclosing the issue
publicly.
